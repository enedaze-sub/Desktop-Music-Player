# 커스텀 테마와 파형

Claude Opus 5.5 MCP의 design_spec으로 색 편집·명칭·파형 가독성 구성을 검토했습니다. 구현은 GPT-6.1 Sol에서 진행했습니다.

기존 네 테마의 색은 유지하며 마지막 표시 이름을 민트 네온으로 바꿉니다. 커스텀 테마는 6색 편집과 기존 테마 복사, HEX 입력을 제공합니다. 테마·파형 선택과 미리보기는 설정창 위에 고정하며 나머지 설정은 스크롤합니다. 실제 플레이어에도 즉시 반영하고 취소하면 복원합니다.

파형은 클래식 막대·LED 계단·미러 막대·라인 스펙트럼입니다. 40px 기준 높이, 최소 20px, 중앙 620px 기준 최대 폭과 밝은 강조색을 사용합니다. 음악의 로그 주파수 24밴드를 표시하며 재생 음량은 조절하지 않습니다. 설정 미리보기만 예시 파형을 사용한다고 명시합니다. 최대 20fps, 최소화·숨김 시 정지하며 분석용 윈도·주파수 구간을 재사용합니다.


v0.2.0: Claude Opus MCP에서 상단 상태 위치·가는 발광 파형·색 편집 구성을 검토했습니다. 상태는 좌우 고정 영역 사이 중앙에 표시하고 창 높이를 줄였습니다. 네온 파형은 실제 24밴드에서 최대 64개의 가는 막대를 보간해 그립니다. 작은 반투명 사각형을 합성해 빛 번짐을 표현하며 블러 디코더나 GPU 효과는 추가하지 않습니다. 커스텀 7색 중 파형은 강조와 독립적입니다. 배경·패널·강조·파형에는 두 색과 방향을 지정하며 설정창의 예시 미리보기와 실제 재생에 같은 렌더러·브러시를 사용합니다.


v0.2.1: 이름별 저장 목록과 JSON 단일·묶음 교환을 추가했습니다. 목록의 추가·이름 변경·삭제와 선택한 테마 편집은 설정 적용 시 한 번에 저장하며 취소 시 되돌립니다. 가져오기 이름 충돌은 기존 항목을 덮지 않고 새 이름을 붙입니다. 상단 테마 선택에 저장 목록을 함께 표시하고 긴 이름이 설정창을 늘리지 않도록 콤보박스 폭 정책을 고정했습니다.

Claude Opus design_spec의 saved_gradient_theme 제안에서 ‘노을빛 살구’와 ‘라벤더 오로라’의 7색·그라디언트·파형 구성을 반영했습니다. 원본 프로필은 assets/theme-presets.json에 있습니다. 본문색과 패널·배경의 시작/끝색 대비 4.5:1 이상을 회귀 검사합니다.

v0.2.2: Claude Opus MCP의 light_sunset_apricot 제안을 반영했습니다. 상아 #FFF6EA→밝은 살구 #FFE3CC 배경, 밝은 패널 #FFFBF4→#FFEEDD, 밤색 본문 #3A2418·보조 #7A5340, 코랄 강조 #F2895C→#E9704F를 사용합니다. 배경·패널 양 끝색에서 본문과 보조 글자 대비를 4.5:1 이상으로 검사합니다. 노을빛 살구와 색 구성을 유지한 라벤더 오로라는 themes.json에 등록해 기본 6종으로 제공합니다. 커스텀은 별도 항목이며 저장 목록은 사용자 테마만 담습니다. assets/legacy-theme-presets-v021.json은 이전 원본을 구분하는 읽기 전용 이전 정보입니다. 정확히 일치하는 제공 원본만 승격하고 직접 편집한 색·그라디언트·파형과 다른 이름의 복사본은 보존합니다.

v0.2.3: 사용자 지정에 따라 노을빛 살구 배경 끝색을 #FFC859로, 라벤더 오로라 배경 끝색을 #3A1C4F로 변경했습니다.
