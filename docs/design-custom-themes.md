# 커스텀 테마와 파형

Claude Opus 5.5 MCP의 design_spec으로 색 편집·명칭·파형 가독성 구성을 검토했습니다. 구현은 GPT-6.1 Sol에서 진행했습니다.

기존 네 테마의 색은 유지하며 마지막 표시 이름을 민트 네온으로 바꿉니다. 커스텀 테마는 6색 편집과 기존 테마 복사, HEX 입력을 제공합니다. 테마·파형 선택과 미리보기는 설정창 위에 고정하며 나머지 설정은 스크롤합니다. 실제 플레이어에도 즉시 반영하고 취소하면 복원합니다.

파형은 클래식 막대·LED 계단·미러 막대·라인 스펙트럼입니다. 40px 기준 높이, 최소 20px, 중앙 620px 기준 최대 폭과 밝은 강조색을 사용합니다. 음악의 로그 주파수 24밴드를 표시하며 재생 음량은 조절하지 않습니다. 설정 미리보기만 예시 파형을 사용한다고 명시합니다. 최대 20fps, 최소화·숨김 시 정지하며 분석용 윈도·주파수 구간을 재사용합니다.


v0.2.0: Claude Opus MCP에서 상단 상태 위치·가는 발광 파형·색 편집 구성을 검토했습니다. 상태는 좌우 고정 영역 사이 중앙에 표시하고 창 높이를 줄였습니다. 네온 파형은 실제 24밴드에서 최대 64개의 가는 막대를 보간해 그립니다. 작은 반투명 사각형을 합성해 빛 번짐을 표현하며 블러 디코더나 GPU 효과는 추가하지 않습니다. 커스텀 7색 중 파형은 강조와 독립적입니다. 배경·패널·강조·파형에는 두 색과 방향을 지정하며 설정창의 예시 미리보기와 실제 재생에 같은 렌더러·브러시를 사용합니다.
