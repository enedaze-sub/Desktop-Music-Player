플레이어의 아래 여백을 줄이고 네온 파형·독립 파형색·그라디언트와 유튜브 재생목록 전체 추가를 보완했습니다.

- 상태 문구는 상단 중앙에 표시합니다. 접힌 최소 높이를 252→224px로 줄였습니다. 기본 80% 배율에서는 202→179px입니다. 이전 최소 높이는 새 높이로 조정하고 별도로 늘린 높이는 유지합니다.
- 네온 파형을 다섯 번째 모양으로 추가했습니다. 실제 오디오를 이용해 중앙선 위아래로 가는 빛 막대를 표시하며 무거운 블러 효과는 사용하지 않습니다.
- 커스텀 테마의 파형 색을 강조색에서 분리했습니다. 기존 6색 설정은 파형 색을 이전 강조색으로 이어받아 유지합니다.
- 배경·패널·강조·파형에 두 색 그라디언트를 각각 지정하며 가로·세로·대각선 방향을 선택합니다. 설정창과 실제 플레이어에 바로 반영하고 취소하면 복원합니다.
- 유튜브 공유 링크·마크다운 링크·프로토콜 없는 주소를 인식합니다. LOCAL 탭에서도 유튜브 링크로 검색하면 자동 전환합니다.
- 재생목록은 300곡 제한 없이 재생 가능한 전체 목록을 불러오고 ‘재생목록 전체 추가 (N곡)’로 원래 순서대로 등록합니다. 목록에 중복 곡이 있으면 순서를 유지합니다. 일반 검색은 10곡씩 페이지를 넘기는 방식을 유지합니다.
- 제공된 재생목록을 실제 검색 화면에서 약 0.75초에 20곡 불러와 전체 추가·원래 순서 보존·재생 유지까지 확인했습니다.
- 92개 회귀 검사와 실제 WAV의 FFT·숨김 시 정지를 확인했습니다. 이번 파형 그리기 중앙값은 모양별 약 0.11~0.41ms, 네온은 약 0.37ms입니다. 최대 20fps이며 PC에 따라 달라집니다.
- 새 EXE에서도 커스텀 7색·그라디언트·5종 파형·취소 복원을 통과했습니다. 제공된 재생목록은 20곡을 약 0.70초에 불러와 전체 추가·순서 보존·재생 유지를 확인했습니다.
