커스텀 테마를 이름별로 저장하고 JSON으로 공유할 수 있습니다. 그라디언트 테마 두 개를 기본 제공했습니다.

- 커스텀 영역의 이름 입력 → ‘이름으로 저장’ → ‘적용’으로 테마를 보관합니다. 상단 테마 목록에서 바로 선택합니다.
- 이름 변경·삭제를 지원하며, 선택한 테마를 편집하고 적용하면 변경 내용을 저장합니다. 테마를 바꿔 비교해도 편집 중인 내용이 유지됩니다. 취소·Esc·닫기는 원래 목록과 외관을 복원합니다.
- 내보내기 메뉴에서 현재 테마 1개 또는 전체 저장 테마를 JSON으로 내보냅니다. 불러오기는 단일·묶음 파일을 지원하며 같은 이름은 (2), (3)으로 추가합니다.
- 7색·4개 영역의 그라디언트·비주얼라이저 사용 여부와 모양을 테마에 포함합니다. 파일 형식을 검사하고 잘못된 파일은 기존 목록을 바꾸지 않습니다.
- 노을빛 살구: 어두운 자주·와인 배경, 상아색 글자, 살구→코랄 강조·막대 파형입니다.
- 라벤더 오로라: 남색→청록 배경, 라벤더→청록 강조와 청록→라벤더 네온 파형입니다.
- 두 팔레트는 Claude Opus MCP 검토를 반영했습니다. 본문과 패널·배경의 양 끝 색 대비를 검사했습니다. 기존 색 조합과 설정은 유지합니다.
- 102개 회귀 검사로 여러 테마 전환·재시작·이름 충돌·JSON 왕복·취소 복원·기본 테마 대비를 확인했습니다.
- 새 EXE에서도 두 저장 테마·단일/전체 JSON 내보내기·다시 불러오기·이름 충돌 보존을 확인했습니다. 유튜브 검색·20곡 재생목록 전체 추가·로컬 영상 검사도 통과했습니다.
