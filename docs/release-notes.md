커스텀 테마와 네 가지 비주얼라이저, 설정창 내부 미리보기를 추가했습니다.

- 커스텀 테마: 배경·패널·본문·보조 글자·강조·테두리 6색을 직접 지정합니다. 색상 선택창·HEX 입력과 기존 테마 색 복사를 지원합니다.
- 설정창 안에서 기존 4종·커스텀 테마와 파형을 바로 비교합니다. 파형 미리보기는 예시이며 실제 재생에서는 오디오 데이터를 사용합니다. 적용은 저장하고 취소·Esc·닫기는 원래 설정을 복원합니다.
- ‘비주얼라이저’ 테마를 ‘민트 네온’으로 변경했습니다. 테마와 파형 사용 여부를 따로 선택합니다. 이전 민트 테마의 자동 파형 설정은 보존합니다.
- 클래식 막대·LED 계단·미러 막대·라인 스펙트럼 4종을 선택하고 저장합니다.
- 파형 영역은 24px에서 40px로 늘렸으며 50% 배율에서도 20px를 확보합니다. 긴 창에서는 중앙에 모아 표시하고 로그 주파수 분석·표시 감도를 개선했습니다. 재생 음량에는 영향을 주지 않습니다.
- 비주얼라이저 사용 시 제목은 한 줄로 표시하며 전체 제목은 마우스를 올려 확인할 수 있습니다.
- ‘배경 이미지 꾸미기’의 말줄임표와 별도 ‘강조색 선택’ 버튼을 제거했습니다. 강조색은 커스텀 테마에서 조절합니다.
- 최대 20fps, 숨김·최소화 시 정지를 유지합니다. 이번 측정의 FFT 중앙값은 약 0.07ms, 파형별 그리기 중앙값은 약 0.09~0.37ms이며 PC에 따라 달라집니다.
- 84개 회귀 검사와 실제 WAV의 재생·FFT 출력·숨김 시 정지를 확인했습니다.
- 새 Windows EXE에서도 5종 테마·커스텀 6색·4종 파형·취소 복원과 타이머 정지를 확인했습니다. 유튜브 검색 페이지와 로컬 영상 검사도 통과했습니다.
